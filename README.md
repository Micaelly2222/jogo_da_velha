# English

## Tic-Tac-Toe

In this project I built a Tic-Tac-Toe game in Python. The goal was to create a simple, interactive implementation of the classic game.

### Overview

Tic-Tac-Toe is a two-player board game where the goal is to mark three squares in a row (horizontal, vertical or diagonal) before the opponent. This project is a Python implementation where two players can compete against each other.

### How to Play

- Open the game file in your preferred Python environment (such as Jupyter Notebook).
- Follow the instructions to select squares on the board and alternate between players (X and O).
- The game announces the winner or a draw when the match ends.

### Languages and Tools

- [Python](https://docs.python.org/3/tutorial/), a high-level programming language
- [Jupyter Notebook](https://jupyter.org/), an interactive environment for creating and sharing code
- [Random](https://docs.python.org/3/library/random.html), a Python module for generating pseudo-random numbers

### Minimum Installation Requirements

Python (version 3.6 or higher)

# Português

## Jogo da Velha

Neste projeto, desenvolvi um Jogo da Velha usando Python. O objetivo era criar uma implementação simples e interativa do jogo clássico.

### Visão Geral

O Jogo da Velha é um jogo de tabuleiro para dois jogadores, onde o objetivo é marcar três casas em uma linha (horizontal, vertical ou diagonal) antes do oponente. Este projeto representa uma implementação do Jogo da Velha em Python, onde dois jogadores podem competir entre si.

### Como Jogar

- Abra o arquivo do jogo em seu ambiente Python preferido (como o Jupyter Notebook).
- Siga as instruções para selecionar as casas no tabuleiro e alternar entre os jogadores (X e O).
- O jogo indicará o vencedor ou um empate quando a partida terminar.

### Linguagens e Ferramentas Utilizadas

- [Python](https://docs.python.org/pt-br/3/tutorial/), linguagem de programação de alto nível
- [Jupyter Notebook](https://jupyter.org/), aplicação online que permite criar e compartilhar código interativo 
- [Random](https://docs.python.org/3/library/random.html), módulo Python para geração de números pseudoaleatórios 

### Requisitos Mínimos de Instalação

Python (versão 3.6 ou superior)
